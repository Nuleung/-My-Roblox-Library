# 🛠️ Roblox Utility Modules
로블록스 개발에 최적화된 유용한 루아 모듈들을 모아놓은 저장소입니다.

## 🗂️ 모듈 목록

### 1. [Referencer](./Referencer.lua)
- **용도**: 테이블 데이터의 깊은 곳(Deep Index)을 캐싱하여 빠르고 안전하게 참조합니다.
- **주요 기능**: 
    - 단일 키(String) 및 경로(Table) 탐색 지원
    - Weak Table 기반 자동 메모리 관리
    - 에러 방지(Defensive Programming) 설계

---

## 🚀 사용 방법
1. 원하는 모듈(` .lua`) 파일을 클릭합니다.
2. 코드를 복사하여 로블록스 스튜디오의 `ModuleScript`에 붙여넣습니다.
3. `require()`를 통해 프로젝트에서 사용합니다.
